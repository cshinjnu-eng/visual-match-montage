# 生图与质量检查

## 先找能成立的对应

用几句话或小表记录参考图的“构图约束”：

| 项目         | 记录内容                                   |
| ------------ | ------------------------------------------ |
| 主锚点       | 是什么；在画面哪里；必要时用归一化坐标描述 |
| 外形与尺度   | 主体边界、占画面比例、开口或圆盘直径       |
| 方向         | 主轴、流向、视线、消失方向                 |
| 负空间与层次 | 哪些区域应留空，前后关系怎样               |
| 光与色       | 必须衔接的明暗大块；可以改变的色相与材质   |
| 自由度       | 允许改变的题材、背景、局部细节、镜头尺度   |

只记录能从图中观察到的内容。坐标可以是估计，需注明；它们是提示和复核依据，不是生图服务保证遵守的几何参数。

跨题材候选要兼顾形态对应与语义距离：发梢分叉呼应树冠，比“把树长在皮肤上”更可信。眼睛与湖泊可以共享一个开口的位置与尺度，不需要把湖水、雪山或绿色液体复制进眼内。若题材无法自然承接原图，换对象、景别或参考图。

主题组与大跨度组应共用同一锚点和画幅，便于比较联想的差别；不必把两组强行做成完全相同的色调。首轮先做少量代表图，用户选定后再扩展，避免先堆几十张再发现方向错误。

## 提示词骨架

按真实任务填具体内容，删除无关字段：

```text
用途：用于连续匹配剪辑的一张独立完整照片。
参考图角色：图 1 只提供构图和视觉锚点；图 2 如有，提供人物身份。
目标：一张可信的 [目标对象、真实存在的形态、摄影视角]。
必须保留：[锚点位置、主体比例、主轴方向、负空间、必要明暗关系]。
可以改变：[环境、材质、颜色和非关键细节]。
保持目标对象自身合理的结构与物理关系。
参考里的地貌、颜色或细节与目标真实性冲突时，优先保证目标可信。
生成完整的新场景；不要把原风景贴进人体，不要混合成畸形对象。
无文字、标签、水印、拼图分隔线。输出画幅为 [本次约定比例]。
```

对人体，具体说清可观察的限制，例如正常眼球与眼睑关系、透明无色泪液、合理指骨结构；不要只写“解剖正确”。医学、显微和标本图的外观不能证明真实组织学关系，重要用途须另找可靠参考验证。

固定人物模式另加身份参考、头部朝向、眼线高度、面部占比、肩线和保留的辨识特征。身体姿态变化若为用户意图，应重新约定锚点。不要把“保持轮廓”误当成“保持同一身份”。该模式尚无本案例的实测成功样本，先做小样检查。

## 生成与保存

- 内置 `image_gen`：遵循当前工具定义；本地参考先 `view_image`。独立交付资产分别生成，概念板不冒充可直接剪辑的独立素材。确认真实输出尺寸、保存路径与文件可读性，项目采用的图片复制到项目中。
- `jmate-image`：只在已选择且可用时采用。读取实时能力与 schema 后再上传/编辑，记录请求 ID、作业 ID、结果 ID、请求质量档、提示词及参考图。原项目修复轮请求 `high`，可作为复现起点；其他任务依用户质量要求和当前服务支持确定。`high` 不等于人体正确，也不证明实际上游模型身份。
- 已提交作业发生超时，先查询原作业；同一请求重试复用请求 ID。已生成但下载失败，只恢复下载。内容或质量改变才新建请求 ID。不把服务故障一概当作提示词问题，也不把所有 HTTP 400/409 都当作可重试错误。
- 每轮先验证 1–2 项。批量前给出由当前小样推算的时间、调用/费用范围（未知就说未知）与并发数；超过五项使用项目内 checkpoint，记录待做、完成、失败。多人并行写独立记录，最后合并，避免覆盖素材来源。
- 创作重做每次针对一个明确问题，保留旧版。连续两次针对性修正仍失败时，先换候选关系或反馈限制；用户授权探索更多时再扩大。基础设施问题不消耗“创作失败”次数，也不自动触发付费重生。

## 四层验收

每项记录 `pass / revise / reject / unverified` 和具体观察。任一必要项为 `revise`、`reject` 或 `unverified`，都不能标为正式通过。不要把分数加权平均到“高分通过”，掩盖结构错误。

| 检查     | 观察方法                                             | 常见失败与处理                                                   |
| -------- | ---------------------------------------------------- | ---------------------------------------------------------------- |
| 主体可信 | 单独看成品，先不看原参考；查看关键局部               | 骨头像珊瑚、皮肤长成山脉、脸变成另一个人：修正或换题材           |
| 构图对应 | 原图与候选同尺寸比较，观察主锚点、比例、方向与负空间 | 位置和尺度偏移：适度裁切/平移/等比缩放；不可修正就重做           |
| 语义跨度 | 两张分别是否可辨为独立对象；关系是否超出换色换材质   | 仍是原地貌贴皮、看不出新题材：重新选择对应对象                   |
| 序列连续 | 看无转场的循环硬切，再看计划使用的节奏与拼图         | 视线需不断重新寻找主体、首尾累积漂移、拼接断裂：重排、对齐或淘汰 |

数值可辅助记录锚点位移、相对尺寸变化、轴角差；本 skill 没有经过标定的通用合格阈值。CLIP 类语义相似度不能单独证明构图相同；对比图也不能代替实际切换预览。

拼图要额外看分割边界：每半张单独好看不代表缝合处自然。不必要求所有纹理逐像素一致，但预期贯穿接缝的主要轮廓应连续。主体真实与拼接效果冲突时，优先换合适配对，或改用硬切。

## 复核顺序与产物

先单图可信度，再原图对照，再串联预览，最后在调色/裁切后的最终画幅复核。循环硬切可用于反复检查某个切点；线性作品不要求最后一张接回第一张。光效不能用来掩盖对位失败。记录到底看了哪些图、哪些序列，不凭联系表声称已看完整片。

建议每个素材保留：来源、参考图与输出路径、所属主题组/跨度组、锚点、提示词、后端及实际返回设置、版本、验收结论与理由。可用 Markdown 表或项目现有清单，无需为少量图片新建系统。
