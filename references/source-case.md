# 来源案例与验证边界

本 skill 提炼自一项“人体 × 自然”的配乐混剪实践，并扩展到连续跨题材穿越。此处保留方法与失败经验；原会话、私人项目路径、素材、服务配置和旧脚本不随仓库公开，也不是使用本 skill 的依赖。

## 原项目的流程

1. 从 Wikimedia 搜索自然照片，整理候选联系表及作者、来源与许可。
2. 以选定的真实照片作为参考，通过图片编辑生成构图呼应的人体或医学风格图像。
3. 检查与重做不可信的主体，建立可用配对池。
4. 分析音乐段落与起音，用 Python、Pillow、NumPy 逐帧合成，交由 FFmpeg 编码。
5. 比较短版与全曲版，按观看反馈修改转场、镜头停留、裁切与调色。

这些流程已在来源项目中执行过，但其特定曲目参数、旧接口、硬编码路径及批量重试逻辑不适合直接复用。

## 有证据的失败与修正

| 失败                                                               | 修正或可复用教训                                               |
| ------------------------------------------------------------------ | -------------------------------------------------------------- |
| 要求每条边与轮廓完全照搬，生成了皮肤上的树、湖泊形眼眶、山脉状皮肤 | 先找真实存在的对应形态；例如用发梢分叉呼应树冠；主体可信度优先 |
| 湖的绿色被带入泪液                                                 | 明确透明无色，并说明不能复制参考中的湖水颜色                   |
| 修正版眼睛更可信，但轮廓不再精确匹配湖泊                           | 真实性与构图分别验收，不因其中一项改善就全部通过               |
| 部分候选反复失败，长发/瀑布联想产生了不想要的人影                  | 淘汰关系或更换参考，不无限重试                                 |
| 滑动擦除拖沓，手骨马赛克停留过长                                   | 改用干脆的分块替换、硬切，并缩短单一技法的持续时间             |
| 自动选择纹理最密的区域裁切                                         | 只作为候选；最终要复核视觉锚点，不能假定纹理密度等于构图价值   |
| 调色重复、颗粒使视频体积变大                                       | 按段落选择效果，避免把同一套滤镜当作必选流程                   |
| 多进程写同一来源记录，条目可能覆盖                                 | 独立写记录再合并                                               |
| 服务上游生成成功，结果存储或下载失败                               | 区分生成与保存，恢复现有结果，避免盲目重复付费生成             |

后续修复轮请求了 `high` 档位，同时调整提示词并人工筛选。不能将质量变化只归因于档位，也不能把请求档位当作实际模型身份的证明。

原项目的卡点问题最后被暂缓，未证实修复；不能把该流程当作已验证的准确对拍算法。医学风格图像也未经过医学专家验证。

## 新增方法与小样

连续穿越采用共同视觉锚点、原始参考防漂移与全序列验收。推荐主题关联与大跨度关联混用：大部分保持主题，在关键切点跳到意外题材。固定人物模式则另用身份参考，不将构图一致等同于身份一致。

初次小样以同一地球图分别生成虹膜与洗衣机舱门：两图都保留蓝白色圆形主体，没有直接把地球地图贴进新对象。但洗衣机外圈过大、上下裁切，因此构图标为 `revise`。虹膜仅通过初步外观检查，不等于医学正确。

随后由 GPT-6 Luna 在不继承原聊天的条件下，读取 skill 独立试作。它自行生成眼睛参考，再生成湖泊与洗衣机样图，并将两张的构图对应标为 `revise`、序列连续标为 `unverified`。这是一次有限的执行测试，不构成模型能力排名或稳定成功率证明。

目前没有完成这两轮小样的对齐后连续试剪、配乐验证或固定人物模式验证。结构校验通过、实际生成成功和成片验收通过是三个不同的结论；后续应通过具体作品继续校准判断标准。
